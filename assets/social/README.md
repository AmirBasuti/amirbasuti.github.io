# Social preview cards

`og-research.png` (homepage) and `og-engineering.png` (`/engineering/`) are
1200 × 630 Open Graph images rendered on 23 October 2026 from local HTML with
headless Chrome. Both are original artwork in the site palette.

- Research: the nine ribbons are decorative, not recorded sensor signals.
- Engineering: the line plots the 93 Milli gold prices (rials per milligram,
  30-day range) in `engineering/milli-price.json`, retrieved 23 Oct 2026 from
  Milli's public widget endpoint and placed by time. It is a dated snapshot.

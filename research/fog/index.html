Task and processing scope

FoG / non-FoG
window detection.

Each two-second window is classified as FoG or non-FoG. Windows advance every 0.5 seconds; zero-phase preprocessing makes this an offline analysis.

Dataset
FoG-STAR: 22 people with Parkinson’s disease. This is temporal FoG detection, a different task from participant diagnosis.
Sensor placement
Left ankle, right ankle, lower back at L3–L5, and the wrist on the most affected side. Each IMU provides accelerometer xyz and gyroscope xyz at 60 Hz.
Window contract
Two seconds, 120 samples per channel, advanced every 0.5 seconds. Four sensors × six channels gives 24 simultaneous channels.
Selected system
Frozen UniShape and MantisV2 representations with cross-attention for the FoG/non-FoG decision.
Analysis context
Zero-phase preprocessing and offline window analysis. The setup does not establish online latency, advance warning or future-event forecasting.

Study scope: temporal FoG detection in FoG-STAR using offline windows. The illustration explains the method; it does not show clinical performance.

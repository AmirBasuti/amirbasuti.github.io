Selected engineering
contributions.

My contributions within the Rasad and Simorgh teams cover integrations, price-history interfaces, persistence and existing service behavior.

01 / Data integrations

HTTP and WebSocket integrations

In Python/FastAPI, I implement and refactor response parsing, timeouts, reconnection and cleanup. My contributions also cover cached responses, freshness, missing readings and lifecycle tests.

The missing interval stays visible while the connection recovers.

02 / Time-series interfaces

Price-history APIs and chart interaction

I contributed to a React/TypeScript dashboard and its APIs: finer detail on zoom, older history on scroll and incoming data aligned with the visible range. I also worked on Persian RTL layouts, localized dates and saved preferences.

The sequence narrows the visible range for more detail, then retrieves older history as the view moves back in time.

03 / Backend & persistence

PostgreSQL migration and typed APIs

I contributed to moving price history from SQLite to PostgreSQL, including decimal precision, SQLAlchemy models and Alembic schema changes. I defined Pydantic API contracts and added database-backed integration-test support.

The example keeps a decimal value consistent across storage and the response contract.

04

Java/Spring service development

I develop and refactor Java/Spring service features, including validation, external API integration, database constraints and caching. I add automated tests around request handling and error behavior.

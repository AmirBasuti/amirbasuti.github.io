# Amir Basuti — academic website

Static personal academic website with research interests, selected work, engineering experience and professional profile links. The scroll-driven SHL story uses original schematic SVG illustrations and supports a motion-off state and the system's reduced-motion preference.

The bibliography distinguishes accepted work from confirmed publication. Only the SHL author manuscript is included; the other selected papers are represented by metadata.

Publish the `main` branch from the repository root using GitHub Pages. No build step is required.

`images/shl-paper-overview.png` is a rendered copy of Figure 1 from Mohebbi et al. (2026), *Early and Late Fusion of Frozen Foundation Models for IMU-Based Human Activity Recognition*, licensed CC BY 4.0. Attribution and the author manuscript link appear beside the figure. This overview includes the study's alternatives; the interactive narrative identifies the selected final late-fusion system and its three nonzero weights. Schematic signal traces are not measured data.
